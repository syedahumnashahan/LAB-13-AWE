
# Full-Stack To-Do Application

## Project Description
A full-stack To-Do application developed using React
and Express.js.

## Technologies Used
- React.js
- Express.js
- Node.js
- Axios
- CSS
- CORS

## Features
- View all tasks
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Prevent duplicate tasks
- Display error messages

## Backend
Runs on http://localhost:5000

## Frontend
Runs on http://localhost:3000

## Installation

### Backend
cd backend
npm install
node server.js

### Frontend
cd frontend
npm install
npm start
